# Thomas Le - Portfolio Website

A modern, responsive portfolio website showcasing my projects, skills, and experience as a Full Stack Developer.

## Live Demo

[View Live Site](https://altterisk.github.io/portfolio/)

## About

Master of Information Technology student at Queensland University of Technology, graduating June 2026. This portfolio highlights my work in web development, AI/ML, game development, and full-stack applications.

## Features

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Dark Theme**: Modern dark mode with blue gradient accents
- **Smooth Animations**: Scroll-based animations and hover effects
- **Project Filtering**: Dynamic filtering by category (All, Group, Personal, Web, AI/ML)
- **Interactive Navigation**: Smooth scrolling with active section highlighting
- **Scroll to Top**: Convenient button for quick navigation

## Technologies Used

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- Intersection Observer API
- GitHub Pages (Deployment)
